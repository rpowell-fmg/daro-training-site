Exercises

  1. Create a new age variable called age_cat that categorizes age into a factor with the following categories (Hint: Be mindful of any missing data):

    • < 30
    • 30-39
    • 40-49
    • 50-59
    • 60-69
    • 70 +
gss_cat_newage<-gss_cat %>% 
  mutate(age_cat = case_when(age < 30 ~ "< 30",
                             between(age, 30, 39) ~ "30-39",
                             between(age, 40, 49) ~ "40-49",
                             between(age, 50, 59) ~ "50-59",
                             between(age, 60, 69) ~ "60-69",
                             age >= 70 ~ "70+",
                             TRUE ~ "-99"),
         age_cat = factor(age_cat))

levels(gss_cat_newage$age_cat)
